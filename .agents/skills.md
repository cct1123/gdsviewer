# Skills registry

No repository skills are registered.

Portfolio policy: a skill captures a reusable project boundary, invariant, or evidence-based workflow that tools cannot infer safely from the task alone. It does not duplicate planner, implementer, reviewer, or reporter behavior, and it is not a generic checklist.

Propose a skill only after the same real need recurs across completed work. A proposal must cite those occurrences, define its trigger and non-goals, identify the invariant it protects, and state how its usefulness will be verified. Until then, keep project rules in `AGENTS.md` and role handoffs in `.agents/*.md`.
