# Agent guidance

[AGENTS.md](../AGENTS.md) is the single source of project instructions.
[README.md](../README.md) describes the viewer and validation commands.

One agent normally inspects, implements, verifies, and reports a change. Separate
roles, handoff documents, and a skills registry are unnecessary for routine work.
Keep reusable project rules in AGENTS.md and task-specific notes in the task.
